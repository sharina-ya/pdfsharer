PDFSharer
PDFSharer — это веб-приложение для совместной работы с PDF-документами. Пользователи могут просматривать PDF, рисовать на страницах в реальном времени, синхронизировать изменения между несколькими участниками и сохранять результаты.

Функциональность
Просмотр PDF: Загрузка и отображение PDF-документов на веб-странице.

Рисование в реальном времени: Пользователи могут рисовать поверх страниц PDF с синхронизацией между всеми подключенными клиентами.

Ластик: Возможность стирания нарисованных элементов.

Изменение цвета и размера кисти: Настройка параметров рисования.

Очистка страницы: Удаление всех рисунков с текущей страницы.

WebSocket-синхронизация: Рисование синхронизируется через WebSocket между клиентами.

Технологии
Backend:
Django

Django Channels

Redis 

Frontend:
HTML/CSS/JavaScript — для пользовательского интерфейса.


Deployment:
Docker/Docker Compose 


Установка
1. Клонирование репозитория
bash
git clone https://github.com/sharina-ya/pdfsharer.git
cd pdfsharer
2. Настройка Docker
Убедитесь, что Docker и Docker Compose установлены на вашем компьютере.

Запустите приложение:

bash
docker-compose up --build

Использование
Загрузите PDF-документ через интерфейс приложения.

Просматривайте страницы документа в режиме прокрутки.

Рисуйте на страницах с помощью инструментов:

Выбор цвета кисти.

Изменение размера кисти.

Ластик для удаления элементов.

Синхронизируйте изменения с другими участниками в реальном времени.
